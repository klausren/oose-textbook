# Commercial Plan — selling this book worldwide 全球发行与销售方案

> Version 1.0 (2026-09-08) · Owner: Ren Zheng
> Goal 目标：把教材卖给**各国软件工程专业学生**，而非只做免费开源教材。
> 前提：保留开源仓库作为**引流层**，付费版作为**产品层**，二者不冲突。

---

## 1. 产品分层 Two editions, one funnel

| | **Open Edition（开源引流版）** | **Commercial Edition（付费完整版）** |
|---|---|---|
| 内容 | Ch 1–3 全文 + 全章目录 + 案例 CareLink 概览 | 全部 20 章 + 习题答案 + AI 提示词库 + CareLink 完整模型附录 |
| 图表 | 全部插图，**CC BY 4.0** 可商用 | 同套插图（高清）+ 可编辑 SVG 源包（教师版） |
| 价格 | 免费 | 电子 $24.99 / 纸质 $44.99 / 捆绑 $54.99 |
| 作用 | 采用登记、口碑、搜索权重、教师试读 | 收入来源 |

**关键逻辑**：图 CC BY 开放 → 教师课堂复用 → 反向带来整本书的销量；
前 3 章免费 → 学生"先试后买"（Leanpub 支持 $0 起步 + 读者自选价）。

## 2. 渠道 Channels（按上线顺序）

| 顺序 | 渠道 | 作用 | 版税/净收益 | 备注 |
|---|---|---|---|---|
| 1 | **Leanpub**（leanpub.com） | 电子主渠道，Early Access 边写边卖 | ~80% − 支付费 ≈ **70%** | 多币种、DRM-free、"买一次终身更新"——正好匹配 AI 内容需频繁更新 |
| 2 | **Amazon KDP** | 纸质 POD，全球学生可及 | 60% − 印刷成本 ≈ **$15–18/册** | 黑白内页控制成本；彩色版另出高价版 |
| 3 | **IngramSpark** | 图书馆 / 书店 / 馆配渠道 | 类似 KDP | 进图书馆 = 机构背书 |
| 4 | **Gumroad / Payhip** | 自有捆绑包：书 + 教师资源 + 课件 | ~95%（仅支付费） | 适合教师版与机构授权 |
| 5 | **Springer / CRC** | 学术背书、图书馆批量采购 | 10–15% | 要求独家商业权，需在 Leanpub 收入稳定后再谈 |
| 6 | **国内出版社** | 中文版 / 影印版 + 规划教材立项 | 8–12% 或一次性 | 对职称与校内认定价值高 |

**定价建议（学生可承受）**：电子 **$24.99**（$19.99 促销）、纸质 **$44.99**、捆绑 **$54.99**；
机构/教师资源年授权 **$199**（含 PPT、题库、答案、SVG 图包）。

## 3. 让"各国学生"真正买得到的四件事

1. **价格分层 by region**：Leanpub 支持地区定价建议；纸质走 KDP 本地印刷（美/英/欧/日）避免跨境运费。
2. **预付与采购**：机构采购需发票与 ISBN —— 必须申请 **ISBN（电子 + 纸质各 1 个）**。
3. **翻译权保留**：许可中明确"翻译权保留"，优先西语、俄语（学生来源匹配）、阿拉伯语（海湾市场）。
4. **无障碍与格式**：EPUB（重排）+ PDF（固定版式）+ 在线 HTML；图必须有 alt text，否则 EPUB 无法进入部分机构采购清单。

## 4. 营销漏斗（低成本、可复用现有资产）

```
GitHub 开源仓库（图 CC BY + 前 3 章免费）
   ↓ 采用登记 issue
教师邮件名单（试读 PDF + 教师资源）
   ↓ 课堂试用
学生购买（Leanpub / KDP）
   ↓ 评价与引用
Springer / 国内出版社提案（有真实采用数据后）
```

- **内容营销**：小红书 / LinkedIn / X 发"AI 时代的 SE 教学"系列图（用书中插图，CC BY 自带传播许可）。
- **教师杠杆**：免费审查版（e-inspection copy）→ 采用登记 → 列入书前致谢 → 形成从众效应。
- **学生杠杆**：每章习题答案只给教师；学生版留"自检清单"，制造教师采购动机。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| **AI 内容过时快** | "买一次终身更新"；每章 AI 部分标注 `ai-assisted` 与版本日期；年度修订 |
| **170 幅图工作量** | 按类型批量生产（见 `templates/figure-system.md` §5） |
| **黑白纸印下彩图失效** | 每幅图必须过灰度审计 |
| **盗版** | DRM-free 反而提升转化；靠"持续更新 + 教师资源"让正版有价值 |
| **独家授权冲突** | 与出版社谈判前，先确认 Leanpub 收入与采用数据，避免过早让渡商业权 |
