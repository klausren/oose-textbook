# Index

References are to **section numbers**, not page numbers. The manuscript has no pagination of its own -- Leanpub, PDF and DOCX each repaginate -- but `5.4` names the same section in all three, so a reference survives a change of format, of font or of edition.

A reference in **bold** is a section whose *heading* uses the term — the section that teaches it. Where no heading does, the references are given plain and unranked rather than guessed at. Identifiers beginning `R-` and `CR-` are requirements and `T-` are test cases; for those the reference is the chapter, because an identifier is introduced once and cited across chapters.

This index is generated from the chapter sources by `build/make-backmatter.py` and is never edited by hand. Regenerate it whenever a chapter is added or a section is renumbered.
